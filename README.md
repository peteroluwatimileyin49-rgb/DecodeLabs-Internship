# DecodeLabs Data Analytics Internship

Data analytics projects completed as part of the DecodeLabs Internship Program.

## Project Overview

This repository documents two stages of an e-commerce sales analysis workflow:

1. **Data cleaning and preparation** — improving data quality and validating the dataset.
2. **Exploratory data analysis (EDA)** — investigating distributions, trends, descriptive statistics, and unusual records.

The work was completed using Microsoft Excel and Google Sheets, with formula-based checks used to validate the results.

## Project 1: Data Cleaning & Preparation

### Objective

Clean and prepare the e-commerce sales dataset for reliable analysis.

### Work completed

- Removed duplicate `OrderID` values.
- Standardized dates to `YYYY-MM-DD` format.
- Filled missing `CouponCode` values.
- Corrected whitespace and formatting inconsistencies.
- Performed formula-based validation checks.
- Verified 1,200 records and reported zero errors in the documented checks.

### Files

- [`Project_1_Data_Cleaning_Report-1.pdf`](Project_1_Data_Cleaning_Report-1.pdf) — data-cleaning report and verification results.
- [`Dataset for Data Analytics _Dataset_Cleaned Excel.xlsx`](Dataset%20for%20Data%20Analytics%20_Dataset_Cleaned%20Excel.xlsx) — cleaned dataset workbook.

## Project 2: Exploratory Data Analysis

### Objective

Analyze the prepared dataset to identify patterns, trends, distributions, and potential anomalies.

### Work completed

- Calculated descriptive statistics, including mean, median, count, and standard deviation.
- Examined the distribution of order values.
- Identified eight high-value outliers using the interquartile range (IQR) method.
- Analyzed yearly trends from 2023 to 2025.
- Documented key observations and conclusions.

### Files

- [`Project_2_EDA_Report-1-1.pdf`](Project_2_EDA_Report-1-1.pdf) — EDA report and statistical findings.
- [`Dataset for Data Analytics _Dataset_Cleaned(1)(1).xlsx`](Dataset%20for%20Data%20Analytics%20_Dataset_Cleaned(1)(1).xlsx) — analysis workbook containing calculations.

## Data Quality and Validation

The cleaning process included duplicate checks, date standardization, missing-value handling, formatting cleanup, and formula-based verification. The detailed procedures and results are available in the Project 1 report.

## Assumptions and Limitations

- The analysis is based only on the provided internship dataset.
- Findings should not be treated as representative of the entire e-commerce market.
- Outliers were identified using the IQR method and should be investigated before being removed or excluded.
- The repository currently contains Excel workbooks rather than a fully automated code-based pipeline, so the analysis depends on the formulas and steps documented in those workbooks.

Additional documentation is available in the [`docs`](docs/) directory.
